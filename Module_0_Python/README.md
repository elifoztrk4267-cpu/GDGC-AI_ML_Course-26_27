# Module_0_Python

**Bu modülde işlenecek konular:** Python programlama diline giriş, veri yapıları, döngüler, fonksiyonlar ve sözlük (dictionary) mantığı.

## 📂 Dosyalar
- `*_Slides.pdf`: Derste kullanılan sunum dosyası.
- `*_Code.ipynb`: Derste eğitmen ile birlikte işlenen, teoriyi pratiğe döken Python kodları.
- `*_Homework.ipynb`: Konuyu pekiştirmeniz için hazırlanmış mini-proje ödevi.

## 🚀 Ödev Nasıl Yapılır?
1. `*_Homework.ipynb` dosyasını açın (Jupyter veya Colab ile).
2. Dosyanın en üstündeki `init` (başlangıç) hücresini mutlaka çalıştırın.
3. Sizden istenen görevleri ilgili hücrelere yazın.
4. En alttaki test hücresini çalıştırarak kodunuzun doğru çalışıp çalışmadığını anında görün!
